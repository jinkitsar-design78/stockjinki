# 영웅문 3종목 단타 세팅 v2 — 삼성전기 주력

범위: 조회·차트 설정만. 주문·자동매매 메뉴는 건드리지 않는다. 계정·비밀번호는 직접 입력.

v1에서 바뀐 점
- [0600]에 분할 기능이 없어 **창 2개 + 연동번호**로 대체
- 5분 차트 MACD를 **3,10,16**으로 통일, MACD GC/DC 신호 추가
- 설정 복제는 **차트틀**(저장 → 적용/독립실행)으로

## 0. 수식관리자 (우클릭 → 수식관리자(M) → 신호검색)

| 이름 | 수식 |
|---|---|
| CrashDry_5m | (기존) |
| BottomConf_5m | (기존) |
| FutGreen_1m | `ma20=avg(C,20,1); ma60=avg(C,60,1); up20=ma20>avg(C,20,4); C>ma20 and up20 and C>ma60` |
| FutRed_1m | `ma5=avg(C,5,1); ma10=avg(C,10,1); ma20=avg(C,20,1); C<ma20 or (ma5<ma10 and avg(C,5,2)>=avg(C,10,2))` |
| MACD_GC | `M=MACD(3,10); S=eavg(M,16); CrossUp(M,S)` |
| MACD_DC | `M=MACD(3,10); S=eavg(M,16); CrossDown(M,S)` |

문장은 한 줄에 하나씩. [검증] 오류 시 한 줄형:
`CrossUp(MACD(3,10), eavg(MACD(3,10),16))` / `CrossDown(MACD(3,10), eavg(MACD(3,10),16))`

## 1. 기준 차트 만들기 (모니터2 위)

[0600] 삼성전기 009150, **5분**, 연동번호 **1**
- 이평(단순) 5·20·60·120
- 지표추가: RSI(14), MACD Oscillator(3,10,16)
- 신호검색적용:
  - CrashDry_5m 파랑 ◆
  - BottomConf_5m 빨강 ▲
  - MACD_GC 분홍 ● (봉 아래)
  - MACD_DC 하늘 ● (봉 위)

→ 우클릭 → 차트틀 적용/관리 → 저장: **`주력5분`**
